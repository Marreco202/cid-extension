# Security Policy

## Supported Versions

Currently, only the latest version of the CiD extension is receiving security updates.

| Version | Supported          |
| ------- | ------------------ |
| > 0.0.x | :white_check_mark: |
| < 0.0.x | :x:                |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

If you discover a security vulnerability within this project, please report it privately. You can do this by using GitHub's private vulnerability reporting feature (if enabled on the repository) or by emailing the maintainers directly. 

We take all security vulnerabilities seriously and will aim to acknowledge your report and will provide a timeline for a resolution and a patch.
